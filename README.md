## Selected work

### Traffic Sign Recognition — 96.97% Top-1 across 43 classes
Benchmarked classical ML against a custom CNN and transfer learning on GTSRB (12,630 test
images), then quantized the winner to Int8 TFLite: **254 KB, 1.9 ms/image, 519 images/s**
at 97.08% Top-1, with Grad-CAM explanations and a Streamlit demo.
[Code](https://github.com/ezz-eldin-emad/traffic-sign-recognition) · [Live demo](https://intelligent-traffic-sign-recognition-system.streamlit.app)

### Medical Agentic RAG — Arabic/English assistant
Agentic pipeline with LLM query routing, Qdrant retrieval over multilingual E5 embeddings,
relevance gating, input/output guardrails, and clinic booking state. FastAPI webhook on
Vercel with a Telegram front end.
[Code](https://github.com/ezz-eldin-emad/medical-agentic-rag) · [Bot](https://t.me/MedicalRag_bot)

### Fashion MNIST Classifier — 89.37% test accuracy
PyTorch model tuned with Optuna (3 hidden layers, 86 units, Adam) and shipped as an
interactive Streamlit dashboard.
[Code](https://github.com/ezz-eldin-emad/fashion-mnist-classifier-dense) · [Live demo](https://fashion-mnist-classifier-dense.streamlit.app)

### Egypt & Saudi Arabia Job Market — 9,500+ listings
Scraped Bayt.com, cleaned through an SQL pipeline, and shipped 12 interactive visualizations
per market plus a cross-market comparison.
[Code](https://github.com/ezz-eldin-emad/Job-Market-Insights-analysis) · [Live demo](https://job-market-insights-analysis.streamlit.app)
